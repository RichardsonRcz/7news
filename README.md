# 公开新闻阅读台 · Chrome 扩展

版本：1.0.0。使用 Manifest V3，Chrome 120 或更新版本。

## 安装

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择此目录：

   `C:\Users\rcz\Desktop\7NEWS\chrome-extension`

   应选择直接包含 `manifest.json` 的文件夹。
4. 在浏览器工具栏的“扩展程序”菜单中，将“公开新闻阅读台”固定到工具栏。
5. 点击扩展图标，即可打开完整阅读页面；已有阅读页时会切换到该页。

已经提供可直接加载的目录。若使用 ZIP，先解压再加载；安装后请保留扩展目录。官方加载说明：https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked

## 刷新方式

- 打开阅读页：读取已保存的收藏、缓存，并采集默认四个新闻通道一次。
- 按 F5 / 浏览器重新加载：重新采集默认四个通道，即使已有缓存也会发起请求。
- 点击“刷新新闻”：执行一次相同的采集，采集过程中按钮暂时禁用。
- 在“采集设置”中，可以单独采集某个通道，或输入自定义检索词。
- 没有定时刷新、浏览器启动采集、通知推送或隐藏后台采集任务。扩展后台仅响应图标点击并打开阅读页。

不需要 Python、启动脚本、本地 HTTP 服务、第三方 RSS 转换服务或 API Key。Chrome 自身需要能够连接 Google News。

## 阅读与数据

- 标题、文章来源、发布时间取自实际 RSS，不生成“独家”前缀、虚构摘要或涨跌判断。
- Reuters、Bloomberg 和官方发布通道按实际来源域名检查；未来日期、无日期、超期条目会排除。
- “Google News 跳转”与“原站文章 · 域名匹配”分别标注。可点击“解析原文地址”，成功后替换为与 RSS 标注来源相符的原站地址。
- 原文解析依赖 Google 当前的接口，可能受到网络或限流影响；失败时保留该条聚合跳转链接，不以网站首页代替。
- 域名匹配不表示已经逐篇核验全文，也不会绕过媒体付费墙。
- 支持时间、来源、主题及语言筛选，支持搜索、收藏、Markdown 导出和 JSON 备份。
- 新闻和收藏使用 `chrome.storage.local` 保存。缓存上限 600 条近期新闻、收藏上限 1000 条；超出 7 天的收藏仍保留。
- “导出当前筛选”遵循当前筛选与排序。

## 迁移旧网页中的收藏

1. 在旧网页的“采集设置 → 离线导入与备份”中导出 JSON 备份。
2. 在扩展的同一位置导入该 JSON 文件。

网页和扩展的本地存储相互独立，不能直接互读。旧版仅保存编号的 `policy_7d_bookmarks` 无法可靠还原完整新闻；完整 JSON 备份可以导入。

卸载扩展或删除浏览器用户配置可能清除扩展数据；迁移前可导出 JSON。更新此本地扩展时，保留目录路径，覆盖文件后在 `chrome://extensions` 点击该扩展的重新加载按钮。

## 权限

- `storage`：保存新闻、收藏。
- `https://news.google.com/*`：读取新闻 RSS 和解析聚合链接。

没有 `alarms`、全站访问、浏览历史、Cookie 或本地程序通信权限。

## 文件

- `manifest.json`：扩展配置与最小权限。
- `background.js`：点击工具栏图标时打开或切换阅读页。
- `reader.html` / `reader.css` / `reader.js`：阅读界面、收藏与筛选。
- `collector.js`：浏览器内的 RSS 采集、来源核对与原文解析。
- `icons/`：扩展本地图标。

所有脚本和样式都包含在扩展中，没有远程脚本和 CDN 依赖。
